# コマンド ライン引数解析 (argparser) 機能仕様

## 概要

コマンド ライン引数解析は、コマンド ラインの文字列を、あらかじめ定義した項目へ振り分ける機能です。  
フラグ、整数、文字列、位置引数を扱い、定義の誤りと利用者が与えた引数の誤りを区別します。

## 解決する課題

コマンド ライン引数を個別に解析すると、名前の照合、値の変換、必須項目の検査、誤りの説明、使い方の生成をコマンドごとに繰り返すことになります。  
定義と使い方を別々に管理すると、変更時に内容に不整合が生じます。

また、プログラムが項目を誤って定義した場合と、利用者が誤った引数を与えた場合では、通知する相手と時点が異なります。  
本機能は、定義、解析、結果の参照を分け、二つの誤りを別の結果として扱います。

## 対応する構文

| 構文 | 受け付ける形式 |
|---|---|
| フラグ | `-v`、`--verbose` |
| 値付きオプション | `-o value`、`--option value`、`--option=value` |
| 複数回指定できるオプション | 値付きオプションの繰り返し |
| 位置引数 | 定義順に割り当て |
| 可変長位置引数 | 位置引数列の末尾で複数の値を割り当て |
| 負の位置整数 | 次の位置引数が整数の場合に位置引数として割り当て |

Table: 引数解析で受け付ける構文と形式

短いオプションを一つの引数へ連結する形式、値を一度に複数指定する形式、`--` 以降を無条件で位置引数にする形式は受け付けません。

## 定義と解析の流れ

利用側は、解析前に項目の名前、種類、必須かどうか、複数回指定できるか、説明、結果の格納先を定義します。  
解析結果は、定義時に指定した格納先へ書き込みます。

指定されなかった項目の格納先は変更しません。  
利用側は解析前に格納先へ値を設定することで、既定値を定義できます。

一つの解析状態を使用する場合は、プロセスの終了時まで状態を保持できます。  
複数の独立した解析を同時に扱う場合は、それぞれの解析状態を明示的に保持します。

## プログラム名

プログラム名は、利用側が指定した名前とします。  
指定がない場合は、起動時のプログラム名からディレクトリ部分を除いた名前とします。

Windows の実行ファイル名の拡張子 `.exe` は、大文字と小文字を区別せずに除きます。  
これにより、Linux と Windows で同じプログラム名になります。  
ほかの拡張子は除きません。

利用側は、プログラム名を取得できます。  
プログラム名が得られない場合は、名前がないことを判別できます。  
使い方の説明には、このプログラム名を表示します。

## 誤りの通知

項目名の重複、位置引数の順序矛盾など、定義側の誤りは解析開始前に検出します。  
複数の定義側の誤りがある場合は、件数と内容をまとめて取得できます。

利用者が与えた引数については、未知のオプション、値の欠落、予期しない値、整数変換の失敗、範囲超過、必須項目の欠落、単数項目の重複、個数超過を区別します。  
誤りの対象と引数列上の位置を、説明とともに取得できます。

## 適用範囲外

- サブコマンドごとに異なる項目集合を持つ構造
- 設定ファイルまたは環境変数との統合
- 複数の項目間の依存関係の検証
- シェル補完スクリプトの生成

## 前提と制約

項目は解析前に定義する必要があります。

結果の格納先は、解析と結果の利用が終わるまで有効である必要があります。

プロセスで共通する解析状態を複数のスレッドから同時に変更する場合は、利用側が呼び出しを直列化する必要があります。
