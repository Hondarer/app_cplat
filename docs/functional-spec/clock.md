# 時計と時刻 (clock) 機能仕様

## 概要

時計と時刻は、経過時間の測定、実時刻の取得、共通の時刻表現、時刻の計算と整形を提供します。

## 解決する課題

時刻の取得方法は、プラットフォームによって基準点、分解能、値の表現が異なります。  
実時刻は時刻同期によって前後するため、経過時間の測定に使うと差分が正しくなりません。

秒とナノ秒を利用側が直接計算すると、桁上がりと桁下がりの正規化を誤る可能性があります。  
時刻を保持する型のレイアウトもプラットフォーム間で一致しません。

本機能は、用途の異なる時計を分離し、共通の時刻表現と計算を提供します。

## 時計の種類

| 項目 | 単調増加クロック | 実時刻クロック |
|---|---|
| 基準点 | 不定 | Unix epoch |
| 時刻同期による補正 | 受けません | 受けます |
| 値の単調増加 | 保証します | 保証しません |
| 主な用途 | 経過時間とタイムアウト | 実時刻の記録と外部との照合 |

Table: 単調増加クロックと実時刻クロックの特性比較

経過時間とタイムアウトには、単調増加クロックを使用します。  
ログの時刻など、外部の時刻と照合する値には実時刻クロックを使用します。

## 共通の時刻表現

共通の時刻表現は、秒とナノ秒を保持し、対応するプラットフォーム間で同じバイナリ レイアウトを持ちます。  
絶対時刻と単調増加クロックの値は同じ表現を使用しますが、異なる基準の値を相互に比較することはできません。

OS の機能との境界では、共通の表現と OS 固有の表現を明示的に変換します。

## 時刻の計算と整形

時刻の正規化、加減算、ミリ秒加算、および二つの時刻のミリ秒差の計算は、成否と計算結果を分けて返します。  
ナノ秒の桁上がりと桁下がりを正規化し、計算結果が表現できる範囲を超える場合は範囲超過として通知します。  
現在時刻からミリ秒を加えた期限の生成でも、範囲を超える場合は範囲超過として通知します。  
中間値の相殺後に結果を表現できる場合は、計算を成功させます。  
ミリ秒未満の差は、負の値も含めて負方向へ切り捨てます。  
計算または期限生成が失敗した場合は、出力先を変更しません。

実時刻は、UTC への分解と、UTC またはローカル時刻の ISO 8601 形式への整形ができます。

## 適用範囲外

- 任意のタイム ゾーンを扱うデータベースと変換
- 日付の加減算、営業日などの暦計算
- 高分解能タイマーによる周期実行

## 前提と制約

単調増加クロックの基準点自体には意味がなく、同じ時計から取得した二つの値の差だけが有効です。

実時刻は時刻同期によって前後する可能性があります。  
処理の前後関係の判定には使用できません。

Windows の単調増加クロックの分解能はミリ秒です。  
これより細かい経過時間は測定できません。

共通の時刻表現のレイアウト互換性は x86-64 を対象とします。
