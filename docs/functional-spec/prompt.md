# プロンプト (prompt) 機能仕様

## 概要

プロンプトは、端末上で一行の文字列を対話的に入力する機能です。  
行編集、入力履歴、横スクロール、入力欄を保った出力、状態表示を提供します。

## 解決する課題

対話入力中に別の出力が発生すると、入力途中の行と出力が混ざり、画面上の入力欄が壊れます。  
長い入力、UTF-8 の文字境界、端末サイズの変更も、単純な一行入力では正しく扱えません。

本機能は、入力状態と画面表示をまとめて管理し、端末へ接続されていない場合は通常の一行入力へ切り替えます。

## 一行入力と履歴

入力中は、文字の挿入、後退削除、前方削除、行頭と行末への移動を行えます。  
カーソル位置と削除位置は UTF-8 のコード ポイント境界に限定します。

確定した入力は履歴へ追加でき、前後の履歴を呼び出して編集できます。  
履歴は呼び出し元を識別する名前ごとに分離します。

利用側は、入力欄の初期値を指定して一行入力を開始できます。  
既存の設定値を修正させる場合など、利用者に同じ内容を打ち直させないためです。  
初期値を入れた入力欄では、カーソルを末尾に置きます。  
履歴を呼び出したあとに最新の側へ戻ると、初期値、または編集途中の内容へ戻ります。

入力欄は一行のため、改行などの制御文字を含む初期値は受け付けません。  
入力欄の上限を超える初期値も、途中で切り詰めずに受け付けません。  
途中で切り詰めると、文字の途中で切れた値を編集させることになるためです。  
いずれの場合も入力を開始せず、誤りとして通知します。

## 入力欄と状態表示

入力が表示幅を超えた場合は、カーソル位置が見える範囲を表示します。  
入力内容自体は切り詰めません。

入力中の出力は、現在の入力欄を一度消去し、出力後に入力欄とカーソルを再表示します。  
標準出力と標準エラー出力のどちらへ出力するかを選べます。

状態行は入力欄の上部と下部に固定し、内容がない状態行は表示しません。  
読み取り開始時、キー入力時、入力中の出力時に端末サイズを確認し、表示を更新します。

## 入力候補の補完

文字の挿入、後退削除、前方削除、または候補の確定を行った直後で、カーソルが行末にあり、入力が空でなく末尾の UTF-8 の文字が完成している場合に、利用側へ入力候補を求めます。  
履歴の呼び出し、初期値の設定、カーソル移動、行全体の消去の直後は候補を求めず、表示中の続きも消去します。

有効な候補が 1 件に定まり、その候補が入力済みの部分より長い場合に限り、続きの部分を灰色で表示します。  
候補が複数ある場合や、入力済みの部分と同じ長さの場合は何も表示しません。  
続きの表示は端末の右端で切り詰めます。  
固定された入力欄では、他のスレッドの出力や端末サイズの変更で入力欄を再表示するときも、続きの表示を保ちます。  
なお、制御文字を含む候補、入力済みの部分と先頭が一致しない候補、入力欄の上限を超える候補は対象から除外します。

続きを表示している状態で Tab または行末での右矢印を入力すると、画面で切り詰められた部分も含む候補の続き全体を入力欄へ補ってカーソルを行末へ移し、続けて次の候補を求めます。  
続きを表示したまま Enter で入力を確定した場合は、表示中の続きを含めず、入力済みの部分だけを確定します。  
その他の編集やカーソル移動を行った場合は、続きの表示を消去して通常の操作を行います。

入力または出力が端末へ接続されていない場合は、候補の補完を行わず、Tab も通常の 1 文字として読み取ります。

## 端末でない場合の扱い

入力または出力が端末へ接続されていない場合は、行編集、履歴、状態行、カーソル制御を使用しません。  
入力は通常の一行読み取り、出力は通常のストリーム出力として扱います。  
入力欄の初期値は使用しません。入力側が行全体を与えるためです。  
初期値の検証は端末かどうかによらず行い、受け付けない初期値は同じく誤りとして通知します。

## 適用範囲外

- 複数行のテキスト編集
- 入力候補の一覧表示
- 構文強調
- 端末の代替画面バッファー
- 複数の入力欄を同時に操作する画面
- 入力履歴の永続化

## 前提と制約

Windows では、プロセスとコンソールが UTF-8 を扱える状態である必要があります。

画面制御を使用する間、同じ端末への出力は本機能が提供する入力欄を保つ経路へ集約する必要があります。  
別の経路から直接出力した場合、入力欄の表示は保証しません。

端末が報告する表示幅を前提とし、文字ごとの表示幅が端末実装と異なる場合の桁位置は保証しません。
